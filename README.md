# Bachelor Automated AI Purple Teaming

Bachelor project about using Generative AI as decision support in offensive and defensive cybersecurity operations.

Docker compose files to be used for installation of nginx/juice-shop server containers.

SOF-ELK is self-installed. Download the VM from: https://github.com/philhagen/sof-elk

Velociraptor Server: https://docs.velociraptor.app/downloads/

## Technologies
- OWASP Juice Shop
- Docker
- Kali Linux
- Velociraptor
- SOF-ELK
- Nginx Server
- AI-assisted pentesting
- AI-assisted log analysis
